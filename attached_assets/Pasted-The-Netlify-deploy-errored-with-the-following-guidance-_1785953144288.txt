**Solution:**

1. Check that `vite` is listed as a dependency (or devDependency) in [`package.json`](https://github.com/ankitkapse594/Ankit-s_Portfolio/blob/main/package.json). It should look like:
   ```json
   {
     "devDependencies": {
       "vite": "^7.3.0"
     }
   }
   ```

2. The `npm install` crash is likely due to a corrupted `package-lock.json`. Try deleting it locally and regenerating it:
   ```bash
   rm package-lock.json
   npm install
   git add package-lock.json
   git commit -m "Regenerate package-lock.json"
   git push
   ```

3. If the issue persists, try clearing Netlify's cache by triggering a new deploy with **"Clear cache and deploy site"** from the Netlify dashboard, as stale cache can sometimes interfere.

4. Optionally, simplify the build command in `netlify.toml` — since Netlify already runs `npm install` during dependency installation, you can change the build command to just:
   ```toml
   [build]
     command = "npx vite build"
   ```
   This avoids running `npm install` twice and reduces the chance of the npm crash affecting the build step.
