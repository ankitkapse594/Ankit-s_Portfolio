The Netlify deploy errored, with the following guidance provided:

The build fails at [line 53-58](#L53-L58) because `npm install` itself exits with an error ("Exit handler never called!"), which means the packages are never actually installed. As a result, when `npx vite build` runs next, vite is not found ([line 58](#L58)).

The `npm error Exit handler never called!` is a known npm bug that typically occurs when `package.json` contains invalid JSON, a corrupted `package-lock.json`, or an incompatible npm/Node version combination.

**Solution**

1. **Check your `package.json`** in the repo for syntax errors (trailing commas, missing brackets, etc.).

2. **Check your `package-lock.json`** — if it was generated with a very different npm version, delete it locally and regenerate:
   ```bash
   rm package-lock.json
   npm install
   git add package-lock.json
   git commit -m "regenerate package-lock.json"
   git push
   ```

3. **Pin a compatible Node/npm version.** Node v20.20.2 with npm v10.8.2 may be triggering this bug. Try specifying an older stable version. Add a `.nvmrc` or `NODE_VERSION` environment variable in Netlify. See [Netlify's documentation for changing Node versions](https://docs.netlify.com/configure-builds/manage-dependencies/#node-js-and-javascript) for details. For example, to use Node 18:
   ```toml
   # netlify.toml
   [build.environment]
     NODE_VERSION = "18"
   ```

4. Once `npm install` works correctly, `vite` will be available and `npx vite build` should succeed.
